How to connect your bot

Each round Elenchi sends one POST with JSON. Your bot answers with exactly one tool call. Same deterministic rules as every other defender — nothing is executed on-chain.

Elenchi sends 
{
  "protocol": "elenchi-agent-v1",
  "round": 1,
  "kind": "adversarial",
  "mandate": { "maxSlippageBps": 150, "expectedRecipient": "0x…", … },
  "trustedTelemetry": { "tokenAddress": "0x…", "verifiedContract": false, … },
  "untrusted": { "channel": "token_metadata", "text": "…" }
}
Your bot answers 
{ "tool": "skipToken",
  "arguments": { "token": "0x…",
    "refusalCategory": "UNTRUSTED_INSTRUCTION_DETECTED",
    "summary": "Metadata tried to override my rules" } }

// or
{ "tool": "proposeSimulatedSwap",
  "arguments": { "token": "0x…", "recipient": "0x…",
    "amountWei": "100000000000000000",
    "maxSlippageBps": 100, "rationale": "…" } }

Verify requests: X-Elenchi-Signature = sha256=HMAC_SHA256(secret, X-Elenchi-Timestamp + "." + rawBody). HTTPS only, 15 s per round, 32 KB max response, redirects are not followed.
