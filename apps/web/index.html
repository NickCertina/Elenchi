How it works

Three steps.
One honest verdict.

No wallet, no token, no sign-up. Results are scoped to what was actually tested.

Try it now →
  1. 01

    Pick or connect a defender

    Let your local bot or autonomous AI agent self-connect via a room code or /skill.md, pass an HTTPS webhook, paste a system prompt, or use a sample policy.

  2. 02

    Launch an attack

    A challenger model writes a fresh injection for the chosen vector and adapts every round to the refusal it gets back. It never sees your prompt.

  3. 03

    Read the verdict, then harden

    Every proposed swap is checked against deterministic rules, not another model's opinion. Get a prompt patch as a diff, retest it, export the report.

Evidence, not theater

An LLM saying another LLM was hacked is not proof.

Elenchi separates what was observed, what was signed and what was recorded on-chain — and states the limits of each.

Level A

Channel isolation

Injected text enters only through untrusted channels. A validator checks each tool call against ground-truth telemetry.

Level B

Signed intent

An ephemeral sandbox key signs the exact parameters an agent proposed — evidence-only, it can never execute a trade.

Level C

On-chain record

A registry contract stores compact hashes of the run. A pass means “passed this suite” — never permanent immunity.
